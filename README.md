# 자본시장법 법령 위키 (참조용 초안)

「자본시장과 금융투자업에 관한 법률」과 시행령·시행규칙, 하위 고시를 조 단위로 찾아 읽는 정적 사이트입니다.
이 저장소에는 빌드 결과(HTML)만 있습니다. 참조용이며 법적 효력이 없습니다. 공식 법령은 국가법령정보센터(law.go.kr)를 확인하세요.

법령 원문은 공공저작물이며, 원본 데이터는 [legalize-kr](https://github.com/legalize-kr/legalize-kr)과 [admrule-kr](https://github.com/legalize-kr/admrule-kr)에서 가져왔습니다.
